# Walker (Spotlight-style search)

Walker is the graphical launcher; Elephant supplies search providers. Walker has limited results unless Elephant is running and providers are installed.

## First launch

~~~bash
walker
~~~

On first launch, Walker generates its default configuration in ~/.config/walker/ (commonly config.toml and a themes directory). Start from the defaults generated by your installed version because theme and configuration schemas can evolve.

## Niri keybinding

Add to the existing binds { ... } block in ~/.config/niri/config.kdl:

~~~kdl
Mod+Space { spawn "walker"; }
~~~

## Theme direction

Use a centered, compact window; dark translucent background; soft rounded corners; subtle borders; light text; muted secondary text; and a blue selection accent. Walker's theme syntax is version-dependent, so this repository intentionally does not replace a generated config.toml with an unverified full config.

## Troubleshooting

~~~bash
systemctl --user status elephant.service
elephant providers list
walker --debug
~~~
